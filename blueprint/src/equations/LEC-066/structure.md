# Structure

See `research/clusters/mordell-elliptic/structure.md`.

For \(k\ne0\), \(y^2=x^3+k\) is a \(j=0\) elliptic curve. Its twist class is controlled by \(k\) modulo sixth powers. Rational points are governed by the Mordell-Weil group; integer points reduce to binary cubic forms and Thue equations.
