# Binary Forms/Thue Cluster

Primary entries:

- `LEC-037`: binary cubic equal to a cube.
- `LEC-038`: mod \(9\) obstruction for a binary cubic equal to a cube.
- `LEC-050`: binary cubic Thue equations.
- `LEC-051`: mod \(9\) obstruction for binary cubic representation of \(1\).
- `LEC-162`: general Thue equation.

Working thesis: the cluster separates local obstruction from global finiteness. `LEC-038` and `LEC-051` are explicit congruence filters. `LEC-050` and `LEC-162` are the global binary-form finiteness layer. `LEC-037` sits between them: a binary cubic superelliptic equation whose elementary Mordell obstruction is a local avatar of the general binary-form problem.
