# Mordell-Elliptic Cluster

Primary entries:

- `LEC-060`: Mordell finite-basis theorem for
  \[
  y^2=x^3-h_2x-h_3.
  \]
- `LEC-066`: Mordell curve family
  \[
  y^2=x^3+k.
  \]
- `LEC-084`--`LEC-092`: special Mordell curves singled out by Mordell.
- `LEC-190`: Birch--Swinnerton-Dyer rank conjecture for
  \[
  y^2=x^3-Ax-B.
  \]

Working thesis: this cluster is one elliptic-curve structure viewed through four different lenses: rational point generation, finite generation, integer point finiteness, and analytic rank. The special equations are not isolated curiosities; they are cubic twists of the \(j=0\) elliptic curve and are test cases for descent, class groups, Thue equations, integral-point algorithms, and Birch--Swinnerton-Dyer heuristics.

Adjacent entries:

- `LEC-067`: local congruence version of the Mordell curve.
- `LEC-068`--`LEC-083`: further Mordell-curve specializations.
- `LEC-062`--`LEC-065`: nearby genus-one equations birationally related to elliptic curves.
