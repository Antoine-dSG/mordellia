# Quartic Genus-One Cluster

Primary entries:

- `LEC-129`: \(ax^4-by^4=c\).
- `LEC-130`: \(x^4-Dy^4=\pm1\).
- `LEC-135`: \(y^2=ax^4+bx^3+cx^2+dx+e\).
- `LEC-136`: \(dy^2=ax^4+bx^2+c\).
- `LEC-140`: \(y^2=Dx^4\pm1\).
- `LEC-145`: \(ax^4+bx^2y^2+dy^4=cz^2\).

Working thesis: this cluster is the quartic side of genus-one arithmetic. Some entries are binary quartic models of elliptic curves or torsors; others are quartic Pell-type equations governed by units in quadratic fields. The central split is rational-point structure versus integral-point finiteness.
