# Classical Conjectures

Entries:

- `LEC-188`: \(\frac4n=\frac1x+\frac1y+\frac1z\), the Erdos--Straus conjecture.
- `LEC-191`: \(x^m-y^n=1\), Catalan's conjecture, now Mihailescu's theorem.

Working thesis: this is a bookkeeping cluster rather than a shared-structure cluster. The two equations are famous conjectural Diophantine problems placed in Mordell's miscellaneous section. One remains open and is controlled only by congruence families and searches; the other is solved by cyclotomic methods.

The cluster should eventually be split unless a real interconnection is found. Its immediate value is comparative: it records one case where Mordell's conjectural statement became a theorem and one where the qualitative structure remains incomplete.
