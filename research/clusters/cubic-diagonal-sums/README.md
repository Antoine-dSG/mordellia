# Cubic Diagonal Sums

Entries:

- `LEC-041`: \(x^3+y^3=az^3\).
- `LEC-043`: \(ax^3+by^3+cz^3+dxyz=0\).
- `LEC-100`: \(x^3+y^3+z^3=n\).
- `LEC-108`: \(z^2=x^3+y^3\).
- `LEC-109`: \(2z^2=x^3+y^3\).
- `LEC-114`: \(x^3+y^3+z^3+w^3=n\).

Working thesis: the two-cube and ternary-Hesse entries are controlled by elliptic and cyclotomic structure, while the three- and four-cube entries are additive problems whose known structure is weaker. The shared first obstruction is congruence modulo \(9\); the deeper layer splits into \(j=0\) elliptic curves, 3-descent in \(\mathbf Q(\rho)\), the Hesse pencil, and large-scale search or Waring-type identities.

This cluster is a depth target because it contains both solved structural cases and still-open additive cases. The most promising structural work is to make the passage between Mordell's cyclotomic descent, Hesse normal forms, and the Mordell-curve cluster explicit.
