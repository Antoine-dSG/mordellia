# Quartic Surfaces And Obstructions

Entries:

- `LEC-119`: \(k_1FF_1=k_2G^2\), with \(F,F_1,G\) ternary quadratic forms.
- `LEC-122`: \(a_1x_1^4+a_2x_2^4+a_3x_3^4+a_4x_4^4=0\).

Working thesis: both entries are quartic surfaces whose arithmetic is governed by the interaction between local obstruction and rational-point generation. `LEC-119` is a 2-adic obstruction theorem for a quartic built from quadratic forms. `LEC-122` is a diagonal quartic surface, a K3 surface in the smooth projective case, where a single suitable rational point can imply density or generate further points.

This is a strong interconnection target because Mordell presents obstruction and construction separately, but modern arithmetic geometry treats both as questions about rational points on quartic surfaces and their auxiliary fibrations.
