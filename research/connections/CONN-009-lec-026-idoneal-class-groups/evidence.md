# Evidence

## Dictionary

| Mordell | Modern |
| --- | --- |
| reduced forms of determinant \(-d\) | classes of discriminant \(-4d\) |
| only boundary solutions | no positive representation |
| rigid factorizations of \(d+z^2\) | Euler--Grube idoneal criterion |
| one class in each genus | class group of exponent at most \(2\) |
| exceptional values of \(d\) | squarefree idoneal numbers with \(d\equiv2\pmod4\), plus \(1,4,18\) |

## Exact Structural Result

For squarefree \(d\equiv2\pmod4\), the field
\(\mathbb Q(\sqrt{-d})\) has discriminant \(-4d\). Louboutin--Newman prove
that strict-positive nonrepresentation is equivalent to
\[
    \operatorname{Cl}(-4d)^2=1.
\]
Kani's class-field formulation identifies this with the ring class field
being an elementary \(2\)-extension. Hence the qualitative yes/no answer is
read from a global Galois/class-group invariant.

The elementary factor identity
\[
    d+z^2=(x+z)(y+z)
\]
shows why idoneal factorization criteria enter.  A positive solution gives a
factorization with both factors greater than \(z\); conversely such a
factorization recovers \(x\) and \(y\).

## Limitation

The criterion is unconditional, but an unconditional explicit list of every
idoneal number is not known.  The displayed list of eighteen exceptions uses
the generalized Riemann hypothesis.
