# Literature

## Modern Formulation

The manuscript `Positive integer points on Mordell--Schinzel surfaces` proves
that the extremal surfaces
\[
    Y_{m,n}=(xyz=x^m+y^n+1)
\]
have positive integer points identified with friezes of a rank-two cluster
algebra with mutation matrix
\[
    \begin{pmatrix}0&m\\-n&0\end{pmatrix}.
\]
In particular, `LEC-117` is \(Y_{2,2}\).

The coefficient-free rank-two cluster algebra with exchange matrix
\[
    B=\begin{pmatrix}0&2\\-2&0\end{pmatrix}
\]
has mutation recurrence
\[
    X_{n-1}X_{n+1}=X_n^2+1.
\]
It is of infinite type: in the rank-two notation, \(mn=4\), whereas the
finite cases are exactly \(mn\le3\).

## Relation To Mordell

Mordell's recurrence is not presented as cluster algebra. The dictionary is:

- Mordell--Schinzel surface \(xyz=x^2+y^2+1\) = extremal cluster/frieze
  surface \(Y_{2,2}\);
- complementary root in Mordell = cluster mutation;
- Mordell's integer sequence = specialized cluster variable sequence;
- Mordell's infinite positive solutions = infinite mutation/frieze set;
- alternate Fibonacci branch = \(mn=4\) tame rank-two cluster branch at
  all-ones specialization.
