# LEC-191

Equation:
\[
    x^m-y^n=1.
\]

This is Catalan's conjecture as Mordell states it. It is now Mihailescu's theorem: the only solution in integers \(x,y,m,n>1\) is \(3^2-2^3=1\).

The proof structure is cyclotomic, using primary cyclotomic units and Galois-module methods. For this project, `LEC-191` is useful as a control case: a concise Mordell conjecture whose later structure is known and decisive.

Interconnections: the real larger family is perfect-power gaps, including Pillai and Fermat-Catalan type equations. The link to `LEC-188` is only that both appear as classical conjectures in Mordell's miscellaneous section.
